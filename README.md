# ポケモンチャンピオンズ向けシミュレーター基盤

このリポジトリは、**ポケモンチャンピオンズの対戦シミュレーター**を作るための最小構成クラス群を提供します。

## 目的

- ポケモン個体のステータス管理
- 性格・技・特性・効果の役割分離
- データセットからのロード経路の準備
- 将来的な拡張（状態異常や複雑な効果処理）を見据えた継承設計

## 実装済み

- `pokemon_simulator/models.py`
  - 6次元ベクトル管理クラス
  - 性格クラス（25種類の標準性格を実装）
  - 技クラス
  - 特性クラス
  - 効果関連クラス
  - 状態異常クラス（麻痺 / 凍り / 火傷 / 混乱 / メロメロ）
  - ポケモンクラス（メガシンカ先・状態異常・状態変化・能力ランク対応）
  - データセットローダークラス
- `pokemon_simulator/battle.py`
  - 6vs6から3体選出するバトル状態管理
  - 交換フェーズ / 変化フェーズ / 技フェーズの解決

## 補足（実数値計算）

一般的なポケモン本編の実数値計算式を採用しています。

- HP:
  - `floor(((2*種族値 + 個体値 + floor(努力値/4)) * レベル)/100) + レベル + 10`
- HP以外:
  - `floor((floor(((2*種族値 + 個体値 + floor(努力値/4)) * レベル)/100) + 5) * 性格補正)`

本実装では、個体値はデフォルト31、レベルはデフォルト50です。

また、デフォルトで **チャンピオンズ努力値スケーリング** を有効化しています。
- チャンピオンズ努力値 `1` を本編努力値 `8` として換算して計算します。
- レベル50前提では、概ね「チャンピオンズ努力値1ごとに実数値+1」と同等の増分になります（性格補正がかかる能力では端数切り捨てあり）。

## 使い方（最小例）

```python
from pokemon_simulator.models import Pokemon, StatVector, Nature

nature = Nature(name="いじっぱり", modifier=StatVector((1.0, 1.1, 1.0, 0.9, 1.0, 1.0)))
base_stats = StatVector((80, 120, 70, 60, 70, 80))
ev = StatVector((0, 44, 0, 0, 20, 2))  # 合計66

p = Pokemon(
    name="サンプルモン",
    base_stats=base_stats,
    nature=nature,
)

p.set_effort_values(ev)
p.calculate_and_assign_real_stats()
print(p.real_stats.values)
```

## バトル進行の概要

- 6vs6のチームから互いに3体選出
- 交換フェーズ（素早さ順、同速は1/2）
- 変化フェーズ（VZ系コマンド。現状はメガシンカのみ実装）
- 技フェーズ（優先度降順→同優先度は素早さ順、同速は1/2）
